## 主要结果

当前联合样本覆盖 `2015Q1-2026Q1`，共 45 个财报季度。全国生猪成交均价历史观察从 `2015-01-05` 开始。

| 关系             | 最强 Pearson 相关系数 | 时间关系            |
| ---------------- | --------------------: | ------------------- |
| 猪价与毛利率     |                 0.797 | 同期                |
| 猪价与净利率     |                 0.789 | 同期                |
| 猪价与归母净利润 |                 0.635 | 同期                |
| 股价与猪价同比   |                 0.419 | 股价领先约 4 个季度 |
| 股价与营收同比   |                 0.361 | 股价领先约 4 个季度 |

历史样本显示，牧原股价往往提前交易猪价和经营拐点。因此，猪价上涨通常有利于盈利，但在涨价已经被市场预期时，股价不一定同步继续上涨。

相关性只用于观察周期传导，不再用于推导目标价。目标价改为量、价、成本和历史周期顶部估值的基本面模型。以脚本最近取得的实际股价 `39.30 元`为基准：

| 情景 | 商品猪售价 | 单位成本 | 年出栏量 | 预测归母净利润 | 核心目标价 |
| ---- | ---------: | -------: | -------: | -------------: | ---------: |
| 压力 | 12.0 元/kg | 12.0 元/kg | 7,600 万头 | -87.5 亿元 | 37.80 元 |
| 基准 | 15.0 元/kg | 11.5 元/kg | 8,000 万头 | 248.5 亿元 | 48.44 元 |
| 景气 | 18.0 元/kg | 11.0 元/kg | 8,400 万头 | 618.1 亿元 | 112.59 元 |

盈利恢复情景使用 2020 年以后成熟规模阶段的历史周期顶部前瞻 PE 作交叉估值；当前亏损或低盈利阶段以配置文件中明确给定的低位 PB 为主，市值/出栏量用于补充验证。所有经营假设均可在 [`config/fundamental_valuation.json`](config/fundamental_valuation.json) 中修改。

### 本轮猪周期顶部条件预测

截至 `2026-07-29`，现货月均价格已从 2026 年 5 月识别谷底反弹，但能繁母猪收缩仍在通过约 10—12 个月生物学滞后向出栏供给传导。结合非洲猪瘟异常周期之外的历史节奏与 `2026-07-28` 生猪期货曲线：

| 项目 | 条件预测 |
| ---- | -------- |
| 当前阶段 | 底部反弹 / 去产能传导期 |
| 历史节奏参考窗口 | 2027 年 3—7 月，不能排除更晚见顶 |
| 时间参考中心 / 供给模型基准高点 | 2027 年 7 月，13.42 元/kg |
| 供给结构情景区间 | 12.93—14.68 元/kg |
| 最远可见期货合约 | LH2705，2027 年 5 月，13.45 元/kg（不是顶部确认） |
| 亏损期 PB 参考价 | 37.80 元（2.5 倍 PB） |
| 当前估值 | 39.30 元，约 2.60 倍 PB |

价格模型从 `3,990 万头`最新能繁母猪出发，以 2023 年母猪对应 2024 年出栏的 `16.96 头/母猪`作为效率基准。基准情景假设生产效率再提高 `2%`、需求价格弹性为 `-0.5`，得到未来出栏约 `69,031 万头`、较 2024 年减少 `1.74%`；均衡价约 `11.23 元/kg`，再乘常规年份月度高点/年均价中位数 `1.196`，得到阶段高点 `13.42 元/kg`。`14.68 元/kg`现在属于效率不再提升、供给偏紧的情景，不再作为中心预测。

期货曲线只覆盖到 `2027 年 5 月`，且价格在最远合约处仍然向上，因此属于右截尾观察：它不能证明 5 月就是最高点。顶部时间仍由常规历史周期节奏给出参考，但 2025 年母猪数据主要约束约 10—12 个月后的供给，无法单独锁定 2027 年顶部。价格情景不是置信区间，需随 2026 年母猪、仔猪、生产效率和出栏体重滚动更新。

去化速度方面，猪粮比、仔猪和二元母猪价格同比仍明显走弱，支持产能继续向 `3,900—3,950 万头`温和去化；但生猪价格近三个月已经反弹，正在缓解淘汰压力，因此深度加速尚未确认。在基准效率和需求弹性下，母猪降至 `3,900 / 3,800 / 3,700 万头`分别对应约 `14.05 / 14.80 / 15.61 元/kg`阶段高点。只有连续两至三个月母猪下降超过 `0.5%`、跌破 `3,900 万头`，且猪粮比持续低于 5、补栏指标继续走弱，才将模型切换到深度去化情景。

## 使用方法

所有命令均在项目根目录执行。

### 1. 更新财务数据

```bash
python scripts/fetch_financial_reports.py
```

脚本拉取资产负债表、利润表、现金流量表，以及按报告期和按单季度的主要财务指标。CSV 使用 `UTF-8 with BOM` 编码，可直接用 Excel 打开。

可调整重试策略：

```bash
python scripts/fetch_financial_reports.py --retries 5 --retry-delay 5
```

### 2. 生成财务分析报告

```bash
python scripts/analyze_financials.py
```

折线图默认只使用年报，保证跨年口径可比；时间线仍包含全部报告期。需要绘制所有累计报告期时：

```bash
python scripts/analyze_financials.py --chart-period all
```

### 3. 生成猪周期、经营和股价联合报告

```bash
python scripts/analyze_pig_cycle.py
```

联网失败时脚本会使用已有缓存。需要禁止缓存并确保结果来自本次请求：

```bash
python scripts/analyze_pig_cycle.py --no-cache
```

### 4. 生成量价成本与基本面估值报告

```bash
python scripts/analyze_fundamental_valuation.py
```

该脚本读取前面生成的猪价和财报数据，并更新公司销售简报、主营构成及未复权股价。关键情景不写死在代码中，可直接修改 `config/fundamental_valuation.json` 后重新运行。联网失败时会使用已有公告缓存；需要禁止缓存时：

```bash
python scripts/analyze_fundamental_valuation.py --no-cache
```

### 5. 分析猪周期决定因素并预测顶部

```bash
python scripts/analyze_pig_cycle_drivers.py
```

脚本拉取仔猪、二元母猪、育肥猪饲料、猪粮比、全国生猪产能和生猪期货远期曲线，计算领先/滞后关系、识别历史谷底与顶部，并通过“母猪存栏→未来出栏→需求弹性→均衡价→阶段高点”的结构模型计算猪价情景，再将基准高点代回牧原基本面估值模型。该脚本依赖第 3、4 步生成的猪价和基本面估值数据。

生成后直接用浏览器打开 `reports/` 下的 HTML 文件。财务与猪周期报告内嵌 Plotly JavaScript；体积较小的基本面估值报告通过 CDN 加载 Plotly，在线浏览时需要联网。

## 分析方法

### 财务状态

财务时间线综合营收与利润增长、ROE、毛利率、资产负债率、流动比率、经营现金流和自由现金流进行机械评分，并标注为“稳健、改善、承压、风险关注”。该评分用于快速筛查，不替代逐项财务分析。

### 猪周期阶段

周度生猪价格聚合为季度均价，并根据季度环比和四季移动均线划分为：

- 上行期：环比至少上涨 5%，且价格位于四季均线上方。
- 下行期：环比至少下跌 5%，且价格位于四季均线下方。
- 高位震荡：价格高于四季均线，但未满足上行条件。
- 低位筑底：价格低于四季均线，但未满足下行条件。

### 相关性

- 猪价与经营指标计算 Pearson 和 Spearman 相关系数，并测试猪价领先 0-4 个季度。
- 股价使用季度后复权收益率，分别测试股价和猪价、营收、毛利率领先或滞后 0-4 个季度。
- “最强关系”是在多个位移中按 Pearson 绝对值选择，存在多重比较偏差。

### 基本面估值

经营预测公式：

```text
生猪收入 = 出栏量 × 平均重量 × 商品猪售价
生猪毛利 = 出栏量 × 平均重量 ×（商品猪售价 - 单位成本）
归母净利润 = 生猪毛利 + 毛利以下及其他业务影响
亏损或低盈利阶段参考价 = 每股净资产 × 亏损期 PB
稳定盈利恢复后的交叉估值 = 正常化归母净利润 × 前瞻 PE ÷ 稀释后总股本
```

当前猪价低于模型成本，PE 不用于当前定价；项目以每股净资产和 `2.5 倍`亏损期 PB 给出约 `37.80 元`参考价。猪价回升情景计算出的利润只用于观察盈利弹性，待连续盈利恢复后才启用正常化 PE 交叉验证。单位成本由“生猪主营成本率 × 公司销售简报加权售价”反推，是报表隐含销售成本，不等于管理层披露的即时养殖完全成本。历史周期顶部按猪价局部高点识别，历史前瞻 PE 带有事后视角，不能直接用于亏损期。

### 猪周期决定因素与顶部

跨年度猪周期的核心反馈链条是：

```text
猪价与饲料决定盈亏
→ 盈亏驱动母猪淘汰或补栏
→ 经过约10-12个月妊娠和育肥滞后
→ 商品猪出栏供给变化
→ 供给改变猪价并再次影响盈亏
```

定量分析同时报告“统计最强领先”和“机制参考领先”。仔猪、母猪价格与猪价往往同期共振，因此首先是景气温度计；能繁母猪存栏才是未来供给的核心数量变量。历史样本中，能繁母猪同比变化领先下一年猪价的 Pearson 相关系数约 `-0.708`，但仅有 10 个年度样本。

顶部时间使用常规历史周期的谷底到顶部月数推导，不把最远期货合约当作顶部日期。顶部价格不再使用期货与历史涨幅加权，而由能繁母猪、次年出栏效率、生产效率变化和需求价格弹性计算供需均衡价，再乘常规年份阶段高点系数。期货曲线只作为市场定价对照；2019—2021 年异常供给冲击不参与阶段高点系数计算。

## 已知限制

- 生猪价格序列始于 2015 年，缺少牧原上市首年 2014 年数据。
- 销售简报从 2016 年开始，2016 年仅覆盖部分月份；稳定的完整年度序列从 2017 年开始。
- 财报和价格均转换为季度频率，样本规模有限。
- 公司销售均价主要对应商品猪，而收入和销量还包含仔猪、种猪，反推重量和成本存在产品结构误差。
- 历史顶部估值使用事后利润，只用于校准估值水平，不代表当时能够准确预测未来利润。
- 全国能繁母猪公开序列目前只更新到 2025 年 10 月，2026 年状态需要由仔猪、母猪价格和期货曲线辅助判断。
- 生猪期货反映市场预期而非确定的未来现货价格，远月持仓和流动性低于近月。
- 常规完整猪周期只有 3 轮，顶部区间是条件情景，不是统计置信区间。
- 最新母猪数据只到 2025 年 10 月，主要约束 2026 年供给；预测 2027 年仍需等待 2026 年母猪、PSY/MSY、仔猪、出栏体重和进口数据。
- `出栏量 ÷ 上年末能繁母猪`只是全国生产效率代理，不能替代真实 PSY/MSY；需求价格弹性也是情景假设，需要随新增样本校准。
- 非洲猪瘟、饲料成本、资本开支、产能利用率、公司治理和估值变化均可能改变历史关系。
- 第三方接口可能调整字段或临时限制访问，更新后应检查数据说明和拉取清单。

## 更新建议

每次更新建议依次运行五个脚本，并检查：

1. `data/拉取清单.json` 是否全部为 `success`；
2. `data/生猪价格_数据说明.json` 的数据日期、来源和警告；
3. `data/牧原月度销售数据.csv` 是否覆盖最新销售简报；
4. 基本面估值的售价、成本、出栏量假设是否仍符合当前经营情况；
5. 生猪期货最远可见合约、曲线是否仍在末端上行，以及能繁母猪最新日期是否变化；
6. HTML 报告中的最新季度是否与已披露财报一致。
