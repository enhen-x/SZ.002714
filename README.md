# SZ.002714

本项目使用 AkShare 拉取牧原股份（`SZ.002714`）历史财务数据，并将全国生猪价格、公司经营指标和后复权股价按季度对齐，用于观察猪周期对盈利能力及市场定价的影响。

项目输出两份交互式报告：

| 报告 | 在线浏览（GitHub Pages） | 仓库文件 |
| ---- | ------------------------ | -------- |
| 财务分析报告：收入、利润、ROE、偿债能力、现金流及逐期财务状态 | [打开报告](https://enhen-x.github.io/SZ.002714/reports/%E8%B4%A2%E5%8A%A1%E5%88%86%E6%9E%90%E6%8A%A5%E5%91%8A.html) | [查看文件](reports/财务分析报告.html) |
| 猪周期与牧原经营分析：猪价、营收、利润率、股价领先/滞后关系及情景目标价 | [打开报告](https://enhen-x.github.io/SZ.002714/reports/%E7%8C%AA%E5%91%A8%E6%9C%9F%E4%B8%8E%E7%89%A7%E5%8E%9F%E7%BB%8F%E8%90%A5%E5%88%86%E6%9E%90.html) | [查看文件](reports/猪周期与牧原经营分析.html) |

> 在线浏览链接需要先在仓库的 `Settings -> Pages` 中选择 `Deploy from a branch`，并将发布来源设为 `main` 分支的 `/(root)`。首次启用后通常需要等待几分钟才能访问。

> 本项目用于数据研究和方法演示，不构成投资建议。相关性不等于因果，统计情景目标价也不等同于 DCF、相对估值或确定性价格预测。

## 主要结果

当前联合样本覆盖 `2015Q1-2026Q1`，共 45 个财报季度。全国生猪成交均价历史观察从 `2015-01-05` 开始。

| 关系             | 最强 Pearson 相关系数 | 时间关系            |
| ---------------- | --------------------: | ------------------- |
| 猪价与毛利率     |                 0.797 | 同期                |
| 猪价与净利率     |                 0.789 | 同期                |
| 猪价与归母净利润 |                 0.635 | 同期                |
| 股价与猪价同比   |                 0.419 | 股价领先约 4 个季度 |
| 股价与营收同比   |                 0.361 | 股价领先约 4 个季度 |

历史样本显示，牧原股价往往提前交易猪价和经营拐点。因此，猪价上涨通常有利于盈利，但在涨价已经被市场预期时，股价不一定同步继续上涨。

以脚本最近取得的实际股价 `39.30 元`为基准，12 个月统计情景如下：

| 情景 | 未来一年猪价 | 营收 | 统计目标价 |       残差区间 |
| ---- | -----------: | ---: | ---------: | -------------: |
| 保守 |         +10% |  +5% |   54.22 元 | 35.02-73.42 元 |
| 基准 |         +20% | +15% |   56.82 元 | 37.62-76.02 元 |
| 乐观 |         +30% | +25% |   59.42 元 | 40.22-78.62 元 |

该模型样本数为 41，R² 为 0.349，残差标准差约 48.9%。区间较宽说明猪价和营收只能解释部分股价波动，估值、成本、产能、市场风险偏好等因素同样重要。

## 使用方法

所有命令均在项目根目录执行。

### 1. 更新财务数据

```bash
python scripts/fetch_financial_reports.py
```

脚本拉取资产负债表、利润表、现金流量表，以及按报告期和按单季度的主要财务指标。CSV 使用 `UTF-8 with BOM` 编码，可直接用 Excel 打开。

可调整重试策略：

```bash
python scripts/fetch_financial_reports.py --retries 5 --retry-delay 5
```

### 2. 生成财务分析报告

```bash
python scripts/analyze_financials.py
```

折线图默认只使用年报，保证跨年口径可比；时间线仍包含全部报告期。需要绘制所有累计报告期时：

```bash
python scripts/analyze_financials.py --chart-period all
```

### 3. 生成猪周期、经营和股价联合报告

```bash
python scripts/analyze_pig_cycle.py
```

联网失败时脚本会使用已有缓存。需要禁止缓存并确保结果来自本次请求：

```bash
python scripts/analyze_pig_cycle.py --no-cache
```

生成后直接用浏览器打开 `reports/` 下的 HTML 文件。Plotly JavaScript 已内嵌，浏览报告不需要联网。

## 数据来源

| 数据           | 主要来源           | 口径                       |
| -------------- | ------------------ | -------------------------- |
| 财务报表       | AkShare / 东方财富 | 报告期累计值               |
| 单季度经营指标 | AkShare / 东方财富 | 单季度值                   |
| 全国生猪价格   | AkShare / 行情宝   | 全国生猪成交均价，周度为主 |
| 牧原股份股价   | AkShare / 东方财富 | 后复权日线                 |
| 股价后备源     | 腾讯证券公开 K 线  | AkShare TLS 失败时启用     |

全国生猪成交均价不是牧原自身商品猪结算价，也不是终端猪肉零售价，但比零售价格更接近养殖企业销售端。股价使用后复权序列计算长期收益，最新实际交易价单独用于情景目标价。

## 分析方法

### 财务状态

财务时间线综合营收与利润增长、ROE、毛利率、资产负债率、流动比率、经营现金流和自由现金流进行机械评分，并标注为“稳健、改善、承压、风险关注”。该评分用于快速筛查，不替代逐项财务分析。

### 猪周期阶段

周度生猪价格聚合为季度均价，并根据季度环比和四季移动均线划分为：

- 上行期：环比至少上涨 5%，且价格位于四季均线上方。
- 下行期：环比至少下跌 5%，且价格位于四季均线下方。
- 高位震荡：价格高于四季均线，但未满足上行条件。
- 低位筑底：价格低于四季均线，但未满足下行条件。

### 相关性

- 猪价与经营指标计算 Pearson 和 Spearman 相关系数，并测试猪价领先 0-4 个季度。
- 股价使用季度后复权收益率，分别测试股价和猪价、营收、毛利率领先或滞后 0-4 个季度。
- “最强关系”是在多个位移中按 Pearson 绝对值选择，存在多重比较偏差。

### 情景目标价

目标价模型使用 12 个月滚动样本：

```text
未来12个月股价收益 = 截距 + β1 × 未来12个月猪价涨幅 + β2 × 营收增速 + 残差
```

模型用后复权价格计算历史收益，再将预计收益应用到最新实际交易价。报告展示的是历史条件回归的情景结果及一个残差标准差区间，不是置信承诺，也没有纳入市盈率、现金流折现或资本成本。

## 已知限制

- 生猪价格序列始于 2015 年，缺少牧原上市首年 2014 年数据。
- 财报和价格均转换为季度频率，样本规模有限。
- 滚动 12 个月样本相互重叠，误差并非完全独立。
- 猪价、营收和利润之间存在共同周期因素，简单回归无法识别因果。
- 非洲猪瘟、饲料成本、资本开支、产能利用率、公司治理和估值变化均可能改变历史关系。
- 第三方接口可能调整字段或临时限制访问，更新后应检查数据说明和拉取清单。

## 更新建议

每次更新建议依次运行三个脚本，并检查：

1. `data/拉取清单.json` 是否全部为 `success`；
2. `data/生猪价格_数据说明.json` 的数据日期、来源和警告；
3. 相关性和模型 R² 是否发生明显变化；
4. HTML 报告中的最新季度是否与已披露财报一致。
