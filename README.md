# SZ.002714

本项目使用 AkShare 拉取牧原股份（`SZ.002714`）历史财务数据，并将全国生猪价格、公司经营指标和后复权股价按季度对齐，用于观察猪周期对盈利能力及市场定价的影响。

## 主要结果

当前联合样本覆盖 `2015Q1-2026Q1`，共 45 个财报季度。全国生猪成交均价历史观察从 `2015-01-05` 开始。

| 关系             | 最强 Pearson 相关系数 | 时间关系            |
| ---------------- | --------------------: | ------------------- |
| 猪价与毛利率     |                 0.797 | 同期                |
| 猪价与净利率     |                 0.789 | 同期                |
| 猪价与归母净利润 |                 0.635 | 同期                |
| 股价与猪价同比   |                 0.419 | 股价领先约 4 个季度 |
| 股价与营收同比   |                 0.361 | 股价领先约 4 个季度 |

历史样本显示，牧原股价往往提前交易猪价和经营拐点。因此，猪价上涨通常有利于盈利，但在涨价已经被市场预期时，股价不一定同步继续上涨。

相关性只用于观察周期传导，不再用于推导目标价。目标价改为量、价、成本和历史周期顶部估值的基本面模型。以脚本最近取得的实际股价 `39.30 元`为基准：

| 情景 | 商品猪售价 | 单位成本 | 年出栏量 | 预测归母净利润 | 核心目标价 |
| ---- | ---------: | -------: | -------: | -------------: | ---------: |
| 压力 | 12.0 元/kg | 12.0 元/kg | 7,600 万头 | -87.5 亿元 | 37.80 元 |
| 基准 | 15.0 元/kg | 11.5 元/kg | 8,000 万头 | 248.5 亿元 | 48.44 元 |
| 景气 | 18.0 元/kg | 11.0 元/kg | 8,400 万头 | 618.1 亿元 | 112.59 元 |

盈利情景以 2020 年以后成熟规模阶段的历史周期顶部前瞻 PE 为核心估值；PB 和市值/出栏量只用于交叉验证。亏损情景使用配置文件中明确给定的低位 PB。所有经营假设均可在 [`config/fundamental_valuation.json`](config/fundamental_valuation.json) 中修改。

## 使用方法

所有命令均在项目根目录执行。

### 1. 更新财务数据

```bash
python scripts/fetch_financial_reports.py
```

脚本拉取资产负债表、利润表、现金流量表，以及按报告期和按单季度的主要财务指标。CSV 使用 `UTF-8 with BOM` 编码，可直接用 Excel 打开。

可调整重试策略：

```bash
python scripts/fetch_financial_reports.py --retries 5 --retry-delay 5
```

### 2. 生成财务分析报告

```bash
python scripts/analyze_financials.py
```

折线图默认只使用年报，保证跨年口径可比；时间线仍包含全部报告期。需要绘制所有累计报告期时：

```bash
python scripts/analyze_financials.py --chart-period all
```

### 3. 生成猪周期、经营和股价联合报告

```bash
python scripts/analyze_pig_cycle.py
```

联网失败时脚本会使用已有缓存。需要禁止缓存并确保结果来自本次请求：

```bash
python scripts/analyze_pig_cycle.py --no-cache
```

### 4. 生成量价成本与基本面估值报告

```bash
python scripts/analyze_fundamental_valuation.py
```

该脚本读取前面生成的猪价和财报数据，并更新公司销售简报、主营构成及未复权股价。关键情景不写死在代码中，可直接修改 `config/fundamental_valuation.json` 后重新运行。联网失败时会使用已有公告缓存；需要禁止缓存时：

```bash
python scripts/analyze_fundamental_valuation.py --no-cache
```

生成后直接用浏览器打开 `reports/` 下的 HTML 文件。财务与猪周期报告内嵌 Plotly JavaScript；体积较小的基本面估值报告通过 CDN 加载 Plotly，在线浏览时需要联网。

| 数据           | 主要来源           | 口径                       |
| -------------- | ------------------ | -------------------------- |
| 财务报表       | AkShare / 东方财富 | 报告期累计值               |
| 单季度经营指标 | AkShare / 东方财富 | 单季度值                   |
| 全国生猪价格   | AkShare / 行情宝   | 全国生猪成交均价，周度为主 |
| 牧原股份股价   | AkShare / 东方财富 | 后复权日线                 |

| 生猪主营构成   | AkShare / 东方财富 | 生猪主营收入、成本和毛利率 |

全国生猪成交均价不是牧原自身商品猪结算价，也不是终端猪肉零售价，但比零售价格更接近养殖企业销售端。后复权股价用于长期收益和相关性，未复权股价用于历史市值与目标价计算。

## 分析方法

### 财务状态

财务时间线综合营收与利润增长、ROE、毛利率、资产负债率、流动比率、经营现金流和自由现金流进行机械评分，并标注为“稳健、改善、承压、风险关注”。该评分用于快速筛查，不替代逐项财务分析。

### 猪周期阶段

周度生猪价格聚合为季度均价，并根据季度环比和四季移动均线划分为：

- 上行期：环比至少上涨 5%，且价格位于四季均线上方。
- 下行期：环比至少下跌 5%，且价格位于四季均线下方。
- 高位震荡：价格高于四季均线，但未满足上行条件。
- 低位筑底：价格低于四季均线，但未满足下行条件。

### 相关性

- 猪价与经营指标计算 Pearson 和 Spearman 相关系数，并测试猪价领先 0-4 个季度。
- 股价使用季度后复权收益率，分别测试股价和猪价、营收、毛利率领先或滞后 0-4 个季度。
- “最强关系”是在多个位移中按 Pearson 绝对值选择，存在多重比较偏差。

### 基本面目标价

经营预测公式：

```text
生猪收入 = 出栏量 × 平均重量 × 商品猪售价
生猪毛利 = 出栏量 × 平均重量 ×（商品猪售价 - 单位成本）
归母净利润 = 生猪毛利 + 毛利以下及其他业务影响
目标市值 = 预测归母净利润 × 历史周期顶部前瞻 PE
目标价 = 目标市值 ÷ 稀释后总股本
```

单位成本由“生猪主营成本率 × 公司销售简报加权售价”反推，是报表隐含销售成本，不等于管理层披露的即时养殖完全成本。历史周期顶部按猪价局部高点识别，并在猪价顶部前 12 个月至后 3 个月窗口中寻找股价高点。历史前瞻 PE 等于“该股价高点的总市值 ÷ 之后四个季度实际归母净利润”，带有事后视角；PB 和市值/出栏量只用于交叉验证。

## 已知限制

- 生猪价格序列始于 2015 年，缺少牧原上市首年 2014 年数据。
- 销售简报从 2016 年开始，2016 年仅覆盖部分月份；稳定的完整年度序列从 2017 年开始。
- 财报和价格均转换为季度频率，样本规模有限。
- 公司销售均价主要对应商品猪，而收入和销量还包含仔猪、种猪，反推重量和成本存在产品结构误差。
- 历史顶部估值使用事后利润，只用于校准估值水平，不代表当时能够准确预测未来利润。
- 非洲猪瘟、饲料成本、资本开支、产能利用率、公司治理和估值变化均可能改变历史关系。
- 第三方接口可能调整字段或临时限制访问，更新后应检查数据说明和拉取清单。

## 更新建议

每次更新建议依次运行四个脚本，并检查：

1. `data/拉取清单.json` 是否全部为 `success`；
2. `data/生猪价格_数据说明.json` 的数据日期、来源和警告；
3. `data/牧原月度销售数据.csv` 是否覆盖最新销售简报；
4. 基本面估值的售价、成本、出栏量假设是否仍符合当前经营情况；
5. HTML 报告中的最新季度是否与已披露财报一致。
